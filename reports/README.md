# Laporan

- `latest.md`: laporan hasil run terbaru, dibuat setelah program dijalankan.
- `comparison.md`: perbandingan baseline dan mild setelah `--compare`.
- `baseline_44mm.pdf`: rekaman laporan sebelum perapian proyek. Angka dan
  pembahasan tetap berguna, tetapi perintah dan nama folder di PDF tersebut
  mengikuti struktur lama. Gunakan README utama untuk menjalankan versi sekarang.

Laporan run menunjuk ke grafik dan angka pada `outputs/`. Hasil run dan laporan
otomatis diabaikan Git agar clone baru tidak membawa tautan hasil yang terputus.
Foto, konfigurasi, inisialisasi, dan kode yang diperlukan disertakan dalam repo.
